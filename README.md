# Crypto Forecasting 

## Project Overview

This project focuses on forecasting cryptocurrency prices using the **AutoRegressive Integrated Moving Average (ARIMA)** model. Historical cryptocurrency price data is analyzed through data preprocessing, exploratory data analysis (EDA), and time series forecasting techniques to predict future price movements. The project demonstrates the practical application of statistical forecasting methods in financial data analysis.

---

## Project Objectives

- Analyze historical cryptocurrency price data.
- Perform data preprocessing and exploratory data analysis (EDA).
- Identify trends and patterns in the dataset.
- Implement the ARIMA (5,1,0) forecasting model.
- Generate and visualize future cryptocurrency price predictions.

Exploratory Data Analysis helped identify important trends and patterns in historical price data, while the forecasting model generated short-term future price predictions through statistical time series analysis.
